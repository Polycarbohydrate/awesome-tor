# Security Policy

This repository contains a Markdown file (README.md) with many links and descriptions. Please open an issue or pull request if you encounter the following:
- A link/website or description that leads visitors to malware
- A link/website or description that leads visitors to scams
- A link/website or description that leads visitors to a phishing page

The list above is non-exhaustive. Please open an issue or pull request if you encounter anything not listed above, but should be removed from this repository for security purposes.
